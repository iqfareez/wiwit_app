# Wiwit Mobile App

This is [wiwit's](https://github.com/iqfareez/wiwit/) mobile client app. You'll need your own instance of [Wiwit](https://github.com/iqfareez/wiwit/) to use this app. 

Like the server's, this app also under active development.

Downlaod the APK from [releases](https://github.com/wiwit-project/wiwit_app/releases/latest) and install on your mobile device (currently only publish for Android)

## Getting Started

Install [Flutter](https://docs.flutter.dev/install). Then run

```shell
flutter run
```
